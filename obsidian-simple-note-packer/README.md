# Obsidian Simple Note Packer 📦✨

Obsidianのノートと埋め込み画像（アセット）をまとめて1つのZIPファイルにエクスポート＆インポートできる**PC（デスクトップ）専用**プラグインだよ！
Markdown標準リンクとObsidian Wikiリンクの自動変換に対応していて、同僚や別Vaultとのノート共有が超スムーズになるよ。

---

## 🌟 特徴・できること

### 1. ノートのZIPエクスポート（画像まるごとパック！）
- **自己完結型パッケージ**:
  - ノートのMarkdownと、本文中で参照されている埋め込み画像（`![[...]]` および `![...](...)`）をひとまとめにしてZIP化！
  - ZIPの中にはノート名と同じフォルダが作られて、その中にMarkdownと画像が全部フラットにまとまるよ。
- **標準Markdownリンクへの自動変換**:
  - エクスポート時、画像リンクを全部標準Markdown形式（`![alt](./image.png)`）に自動変換！
  - VS CodeやGitHub、他のMarkdownビューアで開いてもそのまま画像が表示されて超ベンリ！
- **OSの保存ダイアログ**:
  - エクスポート時にWindows/Macの「名前を付けて保存」ウィンドウが表示され、好きな保存先を指定可能。保存完了後はエクスプローラー等でファイルが自動ハイライトされるよ。
- **呼び出し方**:
  - ノート右上の「その他オプション (`...`)」メニュー ➔ **ZIPパッケージとしてエクスポート (画像同梱)**
  - エディタ内の右クリックメニュー ➔ **ZIPパッケージとしてエクスポート (画像同梱)**
  - ファイル一覧のノート右クリック ➔ **ZIPパッケージとしてエクスポート (画像同梱)**
  - コマンドパレット (`Ctrl+P` / `Cmd+P`) ➔ **ノートと画像をZIPにまとめてエクスポート**

---

### 2. ZIPノートのインポート（モーダルで保存先をサクッと選択！）
- **インポート時のダイアログ選択**:
  - ZIPファイルを選択すると、直感的なモーダル画面がポップアップ！
  - **ノートの保存先フォルダ**: Vault内の全フォルダ一覧からドロップダウンで選択可能（Vault直下 `/` もOK。フォルダ右クリックから開いた場合はそのフォルダがデフォルト選択）。
  - **画像の保存先（二択）**:
    1. **Vaultのアタッチメント設定フォルダ**（例: `99_Assets` など、Vault全体で画像を一元管理したいとき）
    2. **ノートと同じフォルダ**（ノートと画像を同じ場所に置いて自己完結させたいとき）
- **Obsidian Wikiリンクへの自動変換**:
  - 標準Markdown形式のリンク（`![alt](./image.png)`）を、Obsidian標準のWikiリンク形式（`![[image.png|alt]]`）に自動でキレイに変換してノートを開いてくれるよ！
- **呼び出し方**:
  - リボン（左アイコンバー）のアーカイブアイコン ➔ クリック
  - ファイルエクスプローラーのフォルダ右クリック ➔ **このフォルダにZIPパッケージをインポート**
  - コマンドパレット ➔ **ZIPパッケージからノートをインポート**

---

### 3. 設定不要（Zero-Config）
- 面倒な事前設定は一切ナシ！
- 保存先はインポートする時にその場で選べるから、ノートの用途や気分に合わせていつでも切り替えられるよ！
